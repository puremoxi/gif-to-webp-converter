# GIF → WebP Converter — v3.6.12 (Option A, Multi‑Thread, Strict CSP)

**Strict CSP build**: No inline scripts or styles. WebAssembly allowed via `'wasm-unsafe-eval'`. Tailwind and JSZip are self‑hosted.  
**Tip**: The top banner shows `ffmpeg-core.js`, `ffmpeg-core.wasm`, and `ffmpeg-core.worker.js` with a linear progress bar and an `n/3 complete` counter while the engine loads.

## Quick Start (Windows / PowerShell)
```powershell
cd $HOME\OneDrive\Documents\GitHub\gif-to-webp-converter\
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# Tailwind (self-hosted)
npm i -D tailwindcss@3 postcss autoprefixer
npm run build:css

# FFmpeg Core (engine, MT UMD)
npm init -y
npm pack @ffmpeg/core-mt@0.12.6
tar -xf .\ffmpeg-core-mt-0.12.6.tgz
robocopy .\package\dist\umd .\vendor\ffmpeg *.* /E /NJH /NJS
rmdir /S /Q .\package

# FFmpeg Loader (ffmpeg.js + optional chunks)
npm pack @ffmpeg/ffmpeg@0.12.10
tar -xf .\ffmpeg-ffmpeg-0.12.10.tgz
robocopy .\package\dist\umd .\vendor\ffmpeg *.* /E /NJH /NJS
rmdir /S /Q .\package

# JSZip (self-hosted)
npm pack jszip@3.10.1
tar -xf .\jszip-3.10.1.tgz
robocopy .\package\dist .\vendor\jszip jszip.min.js /NJH /NJS
rmdir /S /Q .\package

# Validate manifest (optional)
npm run validate

# Run (strict CSP + COOP/COEP)
npm run serve
# open http://localhost:3000
```

### Where to browse after `npm run serve`
Open: `http://localhost:3000` (no need to point to index.html explicitly).

### Choosing download locations
- Chromium desktop (Chrome/Edge) on `http://localhost` supports **File System Access API**. You’ll see **“Save as…”** dialogs for individual files and ZIP.  
- Other browsers will fall back to standard downloads (usually the system Downloads folder).

## What to Expect
1. On first load, a banner shows FFmpeg engine file loading with a progress bar and `n/3 complete` counter.  
2. Drag & drop GIFs (or click the drop area).  
3. Each queued item shows: **thumbnail**, **resolution** (now first), **FPS**, **frame count**, and **“animation sequence” / “still image”**.  
4. Press **Start Conversion**. Each item shows a real‑time progress bar.  
5. After conversion: per‑item actions include **“Save as…”** (picker first) and **“Direct download”** fallback.  
6. **Download ZIP** bundles all WebPs, also picker-first with fallback.

## Self-hosted JSZip (CSP-safe)
This app uses `script-src 'self' 'wasm-unsafe-eval'`. Do **not** import JSZip from a CDN. Use the Quick Start steps above. The ESM shim is `/vendor/jszip.mjs` (already included) and re-exports `window.JSZip` from `/vendor/jszip/jszip.min.js`.

## Version Manifest Schema
Validated on boot by `validateManifest.cjs` (warnings only).

## CSP Summary
Server sets:
- `Cross-Origin-Opener-Policy: same-origin`
- `Cross-Origin-Embedder-Policy: require-corp`
- `Cross-Origin-Resource-Policy: same-origin`
- `Content-Security-Policy: default-src 'self'; script-src 'self' 'wasm-unsafe-eval'; style-src 'self'; img-src 'self' blob: data:; worker-src 'self' blob:; connect-src 'self'; object-src 'none'; base-uri 'self'; frame-ancestors 'none'`

## Troubleshooting
- **FFmpeg UMD missing**: Ensure both `@ffmpeg/core-mt` UMDs and `@ffmpeg/ffmpeg` UMD (including optional `*.ffmpeg.js` chunks) are in `vendor/ffmpeg/`.
- **JSZip missing**: Alert appears when you try to create a ZIP. Follow JSZip steps above.
- **Tailwind not built**: Yellow banner instructs to run `npm run build:css`.
